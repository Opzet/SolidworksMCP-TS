AutoWorks is a Chat Client and a SolidWorks MCP Server (Model Context Protocol server) 

It enables AI chat to control SolidWorks through natural language, 
Instead of manually clicking through menus, you simply tell it what to design — and it builds it for you.

Example prompts you can use:

"Create a new part, draw a circle with radius 30mm and extrude it 15mm"
"Add a fillet of 2mm to all edges"
"Draw a hexagon and cut extrude it 10mm"
"List all features in the current part"
